# Documentation Audit — curated surface docs against the public barrels

**Date:** 2026-08-01 · **Scope:** every curated surface doc under `packages/ui/docs/`, the package hub (`REFERENCE.md`), the package README, and the barrel doccomments they describe, examined for drift against the actual export surface. **Method:** a mechanical diff per surface — each barrel's export list against the symbols its doc names — plus a relative-link resolution pass over every Markdown file in the package, then a source read of each gap to write its summary. Prose accuracy of existing rows was spot-checked, not verified row by row (see the reliability appendix). **Living record — resolve rows in place with the commit.**

## Executive summary

The docs are in better shape than a full-surface sweep usually finds. Directory-level coverage is complete: every component, module, primitive, provider, and recipe directory has an entry in its doc, and `COMPONENTS.md`, `LAYOUTS.md`, `PROVIDERS.md`, `CORE.md`, `UTILITIES.md`, and `RECIPES.md` match their barrels exactly. The drift that exists is of three kinds, and each has one cause.

The first is symbol-level omission inside otherwise current docs: `PRIMITIVES.md` key-export cells and the `HOOKS.md` type tables had each fallen behind their barrels by a handful of symbols. The second is index-of-indexes staleness — the places that enumerate the docs rather than the code. `docs/README.md`, the package `README.md` layout table, and root `CONVENTIONS.md` §12.2 each listed a subset of what the folder holds, and two links pointed at a `packages/docs` that does not exist. That second kind is the one to watch: a new doc lands in the folder, and the four places that list the folder are not the same change.

The third is a surface that is declared but not used. `ui/types` sits in the `package.json` `exports` map, so it reads as public, yet nothing imports `ui/types` anywhere — not the apps, not `auth` or `shared`, not `packages/ui` itself, which reaches those types 65 times by relative path exactly as it reaches `utilities`. The curated docs index the atomic pieces a consumer renders or calls; a type vocabulary that surfaces through component props is not one, so this sweep gives it no surface doc. §12.1 still governs it, and its TSDoc is in good order.

Two findings stay open because both are API decisions, not docs ones.

## Verified current — recorded so the next sweep doesn't relitigate

Six docs match their barrels symbol for symbol: `COMPONENTS.md` (all 97 component directories), `LAYOUTS.md`, `PROVIDERS.md`, `CORE.md` (all eleven `ui/core` value exports and all four types), `UTILITIES.md`, and `RECIPES.md`. `MODULES.md` covers all five modules, and `PRIMITIVES.md` has a row per primitive directory — the D2 gaps were inside cells, never a missing primitive.

`RECIPES.md`'s kiso tables are accurate against the source tree, including the two entries with no directory of their own: `sun` and `tsunagi` are `sun.ts` and `tsunagi.ts`, not folders, so their absence from a directory listing is not drift. The recipe-engine table matches `src/core/recipe`'s exports. Every other relative link in the package's Markdown resolves.

The `javascript:alert(1` string in [`2026-07-16-CORRECTNESS-AUDIT.md`](2026-07-16-CORRECTNESS-AUDIT.md) is a sanitizer test vector in prose, not a link, and the file is ordinary UTF-8 — `grep` reports it as binary on line length alone.

## Reliability appendix

This audit checked **presence**, not **prose accuracy**. Every barrel export was diffed against the symbols its doc names, so a missing symbol could not hide; but an existing row whose summary has quietly gone stale against its implementation would pass. Summaries were spot-checked where a gap sat next to them and read in full for the rows this change wrote or edited. A prose-accuracy pass over the roughly 300 existing rows is a separate sweep.

Two further limits. TSDoc coverage under §12.1 — whether each public symbol carries a doccomment at all, and whether it is summary-first and in voice — was not audited; this sweep is about the curated docs, and a symbol absent from source TSDoc but present in a doc table would read as covered here. Docs-site demo coverage (`src/docs/demos`) was likewise out of scope. Both are worth their own lens.

Counts are as of this commit and will drift.
