*Changes.* (a) keeps S2 to one file, with the side effects above. (b) widens S2 and, on `DateInputProps`, needs TSDoc and surface-index updates.

**Q2 (S1) — Equality key for a controlled value that is set again.**

*Changes.* The gate in `use-date-input-override.ts:45` and the expected values of the S1 tests.

*Settled.* Instant equality, as Calendar's `sameInstant`. A parent that moves only the time of day drops the typed text.
