# Grid Audit — 2026-09-29

**Lens:** the Grid module (`src/modules/grid`, 147 files, about 35,200 lines) read for correctness, performance, and design. The engine refactor, the cached sort permutation, the render-count gates, and the compiler work have all landed. This sweep asks what each part costs now, and which parts lose to a better pattern.

**Method:** ten read-only sweeps, one for each scope: editing core, editing cells and the new row, the table engine, the data layer and public types, navigation, the sort, filter, and group engines, the group rows and managers, column sizing and pinning, the bodies and windowing, and the toolbar, menus, export, and reorder. Each sweep read every line of its scope and checked its consumers (`src/hooks`, the kata recipes, the demos, the two apps, the tests, and the benches). A second pass judged each claim against the code. A claim marked *probed* was reproduced by a scratch test (jsdom, Chromium, or the compiled run) or by a node microbench against the real modules. Where two sweeps found one fault, the row merges them. The second pass rejected 32 claims (§7).

**Baseline:** 77 grid test files (1,193 cases) pass under jsdom. The React Compiler run has zero skips, and the grid holds two documented opt-outs (`use-grid-data-cursor.ts`). The node and browser bench lines are captured before the first fix.

**Classes:** **A** is mechanical, with no change in behavior. **B** is a fix or a refactor that holds the documented behavior and needs a test. **C** needs a decision from the owner: a visual change, a public API change, or an architectural change (CLAUDE.md §3.1).

**Severity** (defects only): **high** shows wrong data, crashes, or breaks the keyboard or screen-reader path of a core feature. **Medium** is wrong behavior in a plausible configuration. **Low** is an edge case.

**Status:** *Fixed in #N* where that pull request closes the row. *Open* where no pull request closes the row yet (CONVENTIONS §12.4).

## 7. Checked and clean

- The cached sort permutation: keyed on rows, columns, and the signature, independent of `getKey`. The subset shortcut is valid, the custom `sortFn` path is separate, and the parity suite holds it. `parseNumeric` and `NUMERIC_START` accept every documented shape.
- `allocateColumnWidths`: the deficit and surplus paths, the leveling bisection, and the largest-remainder rounding sum exactly to the target. The sizer order, the autosizing flag, `reset`, and `takeControl` are correct. Keyboard resize flips in RTL and clamps to the live floors.
- Pinned offsets are logical and direction independent. `writeFrozenOffsets` runs only when a column moved. Measurement orders every read before the batched writes.
- The resize-drag gate: the memoized headers take only plain values and stable actions. The settle store notifies only changed columns. Truncation subscribes only after contact.
- `GridRow` memo stability: every prop is a primitive or a stable reference. Row keys are stable across sorts. Closing rows keep the open React key.
- Infinite scroll: no double fire and no fire after unmount. The fill latch keys on `count`. `resolveInfiniteScroll` and the trailer order match the TSDoc.
- The edit history engine, the draft store, `isCellEditing`, IME and AltGr seeding, the keystroke path (no grid render per key), the controlled-cell transition machinery, and the async add flow match the editing plan.
- CSV escaping (formula leads, quotes, CRLF), HTML and print escaping, and the XLSX parts apart from D52. The exported rows and columns follow the view, the order, and the selection.
- `GridContext` changes only on a selection flag, the sort, `pinColumn`, or `resizing`; no body cell reads it. The settle, nav, highlight, and density contexts are stable.
- The announcement builders, the RTL mapping of `logicalArrowKey`, the Home, End, and Page edges, `seedCoord`, and the reseat order (key, parent, clamp).
- Rejected on review (32): the claims whose cost was negligible under the compiler or on a discrete gesture (for example the pagination view memo, `settleKey`, the idle reorder `animate`, the XLSX column-letter cache, the row index tuples), the documented trade-offs (the render-time store seat, the text editor for an empty value, the extra render after a row-map change), the exports kept as test anchors (`useGridSelection`, `mode()`, `isAutoSized`, per CLEANUP-AUDIT E4), and the two `'use no memo'` opt-outs, which stay.
