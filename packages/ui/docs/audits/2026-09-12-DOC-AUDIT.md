# Documentation Audit — comment accuracy against the code

**Date:** 2026-09-12 · **Baseline:** `034470d`, the commit that added the [2026-08-02 audit](2026-08-02-DOC-AUDIT.md) · **Scope:** every comment under [`src`](../../src), and the curated surface docs under [`docs/`](..). **Lens:** accuracy. A comment is a defect here when it states something the code no longer does. It is also a defect when it names a file, a symbol, or a test that no longer exists. **Living record — resolve rows in place with the pull request that closes them.**

Rows cite a symbol rather than a line, because a line number stops being true at the next edit. This audit's own first draft proved the point: it cited `map-plat.tsx:778` for a comment its own fix had already moved.

## Executive summary

The defect sat in three places. Six citations named a test, a benchmark, a component, or an audit that does not exist. Seven `{@link}` sites named five symbols that no longer exist. Nine comments across eight files in `modules/map` describe a mechanism the module has since changed. [`HOOKS.md`](../HOOKS.md) also carried three fewer type rows than the hooks barrel exports.

The map rows share one cause, and it is the shape to expect next. The hit-target rule gained a third claimant: a region layer that answers the pointer, added with `map-region/spare.ts`. The comments that enumerate the claimants stayed at two. One sibling (`map-point.tsx`) was updated and the rest were not, so the module stated the rule two ways.

Two open rows carry follow-on work, and one of them is the reason this audit closes fewer categories than it could. Nothing gates the two scanned categories, so both can rot again. The semantic category is swept in `modules/map` only.

The controlled-language regressions this sweep found belong to the August audit's lens, not this one. They are reopened in place there, per [§12.4](../../../../CONVENTIONS.md).

## Method

Five scans ran over `src`, and one subsystem had a per-file read. Each result was checked by hand before it became a row. A clean result is worth as much here as a defect, so the Ruled out section keeps the negative results for the next audit.

The link scan collected every `{@link}` target from a comment and resolved it against the declarations in the package. Read its history as a warning, because its first pass nearly buried five real defects. That pass reported 51 unresolved targets, and a sample of twelve came back false. That sample nearly cost the list. The package places doccomments in three legal spots, which `tsdoc-coverage-boundary.test.ts` enumerates. A scan that reads only `function` / `const` / `type` declarations sees none of them.

The map read found one of those five independently, which is what sent the scan back for a second pass. Once it also read destructuring, object members, and imports, the list fell from 51 to 7, and 5 of the 7 were real. Sample a scan's false positives to fix the scan, never to dismiss its output.

The citation scan extracted every `*.test.ts(x)` and `*.bench.ts(x)` filename named inside a comment, then tested each for existence. This found four of the six closed citation rows. It is the cheapest high-yield scan in this audit, and it is the one to run first next time. Hand the tree roots in directly: [`walk-source.ts`](../../src/__tests__/helpers/walk-source.ts) prunes `__tests__` and `__benchmarks__` by default, and three of the four defects lived inside those trees.

The default-value scan compared each `@defaultValue` claim against the destructuring defaults in the same directory. The modal-verb scan repeated the August audit's language scan at that audit's own scope. The index scan duplicated work that [`surface-index.test.ts`](../../src/__tests__/docs/surface-index.test.ts) already does on every run. The one thing worth recording is why that test missed the gap it found; see the index row below.

No scan reads whether a comment still describes what its code does, so `modules/map` had a per-file read instead. It is the highest-churn subsystem, at 73 files changed since the baseline. It returned nine comments against about 90 minutes of read. That rate is the number to plan the remaining subsystems against.

## Open

**Neither scanned category has a gate, against this repository's own pattern.** #1041 closed its coverage category by adding [`tsdoc-coverage-boundary.test.ts`](../../src/__tests__/boundary/tsdoc-coverage-boundary.test.ts) and wrote "This category cannot drift again without a red test." This audit closed thirteen rows across two mechanically checkable categories and added no test, so both can rot exactly as they did.

The citation scan is the cheaper of the two. It needs a regex over file text and a membership test against a set of basenames, with no compiler API. [`internal-barrel-boundary.test.ts`](../../src/__tests__/boundary/internal-barrel-boundary.test.ts) already holds that shape.

The link scan needs a checker. Its cheapest home is a second `it()` inside `tsdoc-coverage-boundary.test.ts`, which already builds a program over every barrel. That also removes the false-positive class by construction, rather than by the three special cases the Method section describes.

**`TouchTarget` has no browser pin for the claim its doccomment makes.** The comment says the floor holds the activation region rather than the visible bounds. [`touch-target.test.tsx`](../../src/__tests__/primitives/touch-target.test.tsx) asserts the floor classes under jsdom, which is the right environment for a class assertion ([§10.5](../../../../CONVENTIONS.md)). No test measures the geometry those classes resolve to. `grid-target-size.test.tsx` is not that pin: it covers the grid's own `::before` expansion, a different mechanism. The correction made the citation resolve, which also made the gap quieter. The doccomment now states the gap in the file where a reader stands when it matters.

**The semantic category is swept in `modules/map` only.** No scan reads whether a comment still describes what its code does, so each subsystem needs its own per-file read. `modules/map` is done, and these stay unread: `modules/grid` (33 files changed since the baseline), `components/pdf-viewer` (27), `recipes/kiso` (24), `modules/chat` (22), `recipes/kata` (20), and `modules/chart` (19). Recount before you plan, with `git diff --numstat 034470d..HEAD -- packages/ui/src`, because those figures move with every merge. Take them one subsystem to a change, largest first.

Two of the unread subsystems carry a known risk. `components/pdf-viewer` arrived by vendoring, and one donor-repo reference has already been found there, so read its comments for names that never existed in this package. `modules/chart` and `modules/map` split a range legend between them, and the prose split with it, so read both ends of that move together.

## Ruled out

**Every `{@link}` target resolves, now that the five above are fixed.** Two sites still read as unresolved and are not. [`link-syntax.ts`](../../src/docs/engine/api-reference/link-syntax.ts) and [`extract-doc.ts`](../../src/docs/engine/api-reference/engine/extract-doc.ts) document the `{@link …}` grammar itself, so their targets are the placeholder and the delimiter.

**The `@defaultValue` claims are accurate.** All 529 of them. One scan hit needed a hand check and did not survive it: `ChartReferenceLine.dashed` documents `@defaultValue true`, and the code reads `line.dashed !== false`. The claim is right; the scan had matched an unrelated default in a sibling file.

**The package carries no marker debt.** No `TODO`, no `FIXME`, no `HACK`, no `XXX` outside a string, and no `@deprecated`. Staleness here is silent prose, never a flagged marker, so a marker sweep finds nothing.

**The `vector-effect` prose in `modules/map` is correct.** Three comments discuss `vector-effect="non-scaling-stroke"` after the module took over its own stroke scaling. Each explains why the module does *not* use it. That is historically aware prose, not drift.

**The component, module, and primitive indexes are not stale.** [`surface-index.test.ts`](../../src/__tests__/docs/surface-index.test.ts) checks those three per directory, matching the granularity [§12.2](../../../../CONVENTIONS.md) sets, and the August audit walked the same ground. A symbol-level scan reports false gaps against them.
