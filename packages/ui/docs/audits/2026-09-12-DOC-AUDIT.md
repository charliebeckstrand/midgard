# Documentation Audit — comment accuracy against the code

**Date:** 2026-09-12 · **Scope:** every comment under [`src`](../../src), and the curated surface docs under [`docs/`](..). **Lens:** accuracy. A comment is a defect here when it states something the code no longer does. It is also a defect when it names a file, a symbol, or a test that no longer exists. **Method:** five scripted scans, each checked by hand before it became a row. **Living record — resolve rows in place with the pull request that closes them.**

## Executive summary

The package holds about 37000 comment lines across 1335 source files, and the boundary suite already pins the structural categories. The 529 `@defaultValue` claims agree with the code. The package carries no `TODO`, no `FIXME`, no `HACK`, and no `@deprecated`.

The defect sat in three places. Six citations named a test, a benchmark, a component, or an audit that does not exist. Seven `{@link}` sites named five symbols that no longer exist. Seven comments in `modules/map` describe a mechanism the module has since changed. [`HOOKS.md`](../HOOKS.md) also carried three fewer type rows than the hooks barrel exports.

The map rows share one cause, and it is the shape to expect next. The hit-target rule gained a third claimant: a region layer that answers the pointer, added with `map-region/spare.ts`. The comments that enumerate the claimants stayed at two. One sibling (`map-point.tsx`) was updated and the rest were not, so the module states the rule two ways.

Two rows stay open, and one of them is a regression. The [2026-08-02 audit](2026-08-02-DOC-AUDIT.md) recorded the modal-verb category closed across `src`. It has since drifted back to 89 sites in 74 files. The semantic category is swept in `modules/map` only; the other churned subsystems stay unread.

## Method

Five scans ran over `src`, and one subsystem had a per-file read. Each result was checked by hand before it became a row. A clean result is worth as much here as a defect, so the Ruled out section keeps the negative results for the next audit.

The link scan collected every `{@link}` target from a comment and resolved it against the declarations in the package. Read its history as a warning, because its first pass nearly buried five real defects. That pass reported 51 unresolved targets. A sample of twelve came back false, and that nearly cost the list. The package builds its contexts as `export const [FooContext, useFoo] = createContext(...)`. A scan that reads only `function` / `const` / `type` declarations does not see a destructured pair.

The map read found one of those five independently, which is what sent the scan back for a second pass. Once it also read destructuring, object members, and imports, the list fell from 51 to 7, and 5 of the 7 were real. Sample a scan's false positives to fix the scan, never to dismiss its output.

The citation scan extracted every `*.test.ts(x)` and `*.bench.ts(x)` filename named inside a comment, then tested each for existence. This found four of the six closed citation rows. It is the cheapest high-yield scan in this audit, and it is the one to run first next time.

The default-value scan compared each `@defaultValue` claim against the destructuring defaults in the same directory. The index scan compared the `utilities`, `core`, and `hooks` barrels against their surface docs. The modal-verb scan repeated the 2026-08-02 language scan at that audit's own scope, which excludes tests, benchmarks, and the demo tree.

No scan reads whether a comment still describes what its code does, so `modules/map` had a per-file read instead. It is the highest-churn subsystem, at 73 files changed since the 2026-08-02 baseline. It returned seven findings against about 90 minutes of read. That rate is the number to plan the remaining subsystems against.

## Open

**89 modal verbs across 74 files.** `may` accounts for 59 and `should` for 30. Rule 10 admits `must` for a requirement and `can` for a possibility, and admits neither of these. The 2026-08-02 audit closed this category across `src` at this same scope, so every site is drift that arrived with the 49 commits since. The map module holds the largest share, which matches its churn. Each site takes a per-site call. Most `may` cases take `can`. Most `should` cases need a rewrite to the simple present, not a swap to `must`.

**Nine sentences over the rule 6 limit in the living Markdown, and one modal.** The 2026-08-02 audit closed both categories in `docs/` and [`REFERENCE.md`](../../REFERENCE.md). The breaks are in [`UTILITIES.md`](../UTILITIES.md) (four), [`PRIMITIVES.md`](../PRIMITIVES.md) (two, one of which also carries the `may`), and one each in [`CORE.md`](../CORE.md), [`HOOKS.md`](../HOOKS.md), and [`RECIPES.md`](../RECIPES.md). Count the `·`-separated name lists in [`COMPONENTS.md`](../COMPONENTS.md) as index scaffold, not as sentences; a scan that splits on punctuation reports three false breaks there.

**`TouchTarget` has no browser pin for the claim its doccomment makes.** The comment says the floor holds the *activation region* rather than the visible bounds, and that axe cannot see it. `__tests__/primitives/touch-target.test.tsx` asserts the classes under jsdom, which is the correct environment for a class assertion ([§10.5](../../../../CONVENTIONS.md)). No test measures the resulting geometry in a browser. `grid-target-size.test.tsx` is not that pin: it covers the grid's own `::before` expansion, a different mechanism. This audit corrected the citation and did not close the coverage gap.

**The semantic category is swept in `modules/map` only.** No scan reads whether a comment still describes what its code does, so each subsystem needs its own per-file read. The population is the 418 source files whose code changed since the 2026-08-02 baseline. `modules/map` (73 files) is done, and these stay unread: `modules/grid` (33), `components/pdf-viewer` (27), `recipes/kiso` (24), `modules/chat` (22), `recipes/kata` (20), and `modules/chart` (19). Take them one subsystem to a change, largest first.

Two of the unread subsystems carry a known risk. `components/pdf-viewer` arrived by vendoring, and one donor-repo reference has already been found there, so read its comments for names that never existed in this package. `modules/chart` and `modules/map` split a range legend between them, and the prose split with it, so read both ends of that move together.

## Ruled out

**Every `{@link}` target resolves, now that the five above are fixed.** All 3079 sites, against 1650 distinct targets. Two sites still read as unresolved and are not. [`api-reference/link-syntax.ts`](../../src/docs/engine/api-reference/link-syntax.ts) and [`engine/extract-doc.ts`](../../src/docs/engine/api-reference/engine/extract-doc.ts) document the `{@link …}` grammar itself, so their targets are the placeholder and the delimiter, not symbols.

**The `@defaultValue` claims are accurate.** All 529, across 218 files. One scan hit needed a hand check and did not survive it: `chart-reference-lines.tsx:54` documents `@defaultValue true` for `dashed`, and the code reads `line.dashed !== false`. The claim is right; the scan had matched an unrelated default in a sibling file.

**The package carries no marker debt.** No `TODO`, no `FIXME`, no `HACK`, no `XXX` outside a string, and no `@deprecated`. Staleness here is silent prose, never a flagged marker, so a marker sweep finds nothing.

**The `vector-effect` prose in `modules/map` is correct.** Three comments discuss `vector-effect="non-scaling-stroke"` after the module took over its own stroke scaling. Each explains why the module does *not* use it. That is historically aware prose, not drift.

**The component, module, and primitive indexes are still not stale.** This repeats the 2026-08-02 finding and holds. Those three documents index a directory per entry by design ([§12.2](../../../../CONVENTIONS.md)), so a symbol-level scan reports false gaps.
