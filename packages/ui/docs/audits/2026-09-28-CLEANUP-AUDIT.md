# Cleanup Audit — 2026-09-28

**Lens:** what the two long migrations left behind now that they have landed: density from JS to CSS (the VARIANTS, ENGINE, and PRE-PAINT plans, through #1573), and React Compiler readiness (the EFFECT-EVENT and GRID-DATA-SPLIT plans, and the `perf(ui): let the React Compiler compile …` series).

**Method:** seven read-only sweeps, one for each of these: the density API and providers, the recipes, the components and modules (with the apps), the compiler residue, the tests and gates, the docs and TSDoc, and dead exports (a ts-morph import graph over `apps/*` and `packages/*`). Each claim below was checked against the tree with a grep, a class-output probe (`tsx` over the kata), a compiler probe (`babel-plugin-react-compiler` 1.0.0 on a scratch copy), or a test run. Rows marked *lead* were not reproduced.

**Classes:** **A** is mechanical, with no change in behavior. **B** is a small refactor that holds behavior but needs a test run. **C** needs a decision from the owner: a visual change, a public API change, or a policy change.

**Status:** *Fixed in #N* means that pull request #N closes the row (CONVENTIONS §12.4).
