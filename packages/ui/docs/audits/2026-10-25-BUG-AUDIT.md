### B02-C01

- File: `scripts/docs-server.ts`
- Mechanism: `scripts/docs-server.ts:129` `const server = createServer(async (request, response) => {`. `:141-145` passes `new URL(request.url ?? '/', 'http://localhost').pathname` to `resolveFile` with no guard. A request-target that starts with `//` and holds a bad authority makes `new URL` throw. The rejection of the async listener is unhandled, and Node exits.
- Trigger: `GET //[ HTTP/1.1`, `GET //:99999 HTTP/1.1`, or `GET http://a:99999/ HTTP/1.1`. Each exits the process in a local run (caller and overturn pass, Node 22).
- Documented intent: `:155` "A file that the server cannot read gives 500, and the server keeps running." `:71-72` a path that does not decode gets 400.
- Reach: shipped. `Dockerfile.docs:53` `CMD ["node", "scripts/docs-server.js"]`, `Dockerfile.docs:11` `ARG NODE_VERSION=24`, `.do/app.yaml:151` `instance_count: 1`. Nothing in `.do/app.yaml` says the ingress rejects such a target. A live probe was not run. The crash path is live since #2969 moved the docs to this server.
- Severity: high. One request takes the only instance of the site down until App Platform restarts it.
- Prior art: none.
