# Chart Audit — 2026-09-28

**Lens:** the Chart module (`src/modules/chart`, 85 files, about 20,900 lines) read for correctness, performance, and design. Much of the module predates the current engine, the render-count gates, and the compiler work. This sweep asks what each part costs now that one engine carries every chart.

**Method:** seven read-only sweeps, one for each scope: engine core (layout, scale, tier, time), geometry and hit test, interaction hooks, frame and legend, marks and labels, the cartesian charts, and the other charts. Each sweep read every line of its scope and checked its consumers (`modules/map`, `components/sparkline`, the demos, the tests, and the benches). A claim marked *probed* was reproduced by a scratch test or a node microbench against the real modules. Where two sweeps found one fault, the row merges them.

**Baseline:** 43 chart test files (681 cases) pass under jsdom and under the compiler. `chart-geometry`, `chart-scale`, `chart-layout`, and `chart-resize` bench lines were captured before any change. No chart function is in the compiler skip ledger.

**Classes:** **A** is mechanical, with no change in behavior. **B** is a fix or a refactor that holds the documented behavior and needs a test. **C** needs a decision from the owner: a visual change, a public API change, or an architectural change (CLAUDE.md §3.1).

**Status:** *Fixed in #1637* where that pull request closes the row. *Part fixed in #1637* where the owner took one part of a row and deferred the rest. *Open* where no pull request closes the row yet. *Declined* where the owner chose to leave a row as it is (CONVENTIONS §12.4).
